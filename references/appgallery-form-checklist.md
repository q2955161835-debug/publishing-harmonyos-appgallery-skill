# AppGallery Connect 字段、素材与合规清单

本清单用于 HarmonyOS 应用的 `应用信息`、`软件包管理`、待发布版本和审核驳回整改。字段名称、必填性和限制会变化：执行时先读取当前页面，再用当前华为官方文档复核。本清单于 2026-08-11 按当前门户与审核指南核对。

## 1. 状态和证据规则

每一行只能标记为：

| 状态 | 含义 | 能否进入最终提交摘要 |
| --- | --- | --- |
| `PASS` | 当前值真实、适用、已保存并在刷新/重进后仍存在 | 可以 |
| `N/A` | 依据当前包、代码、地区或业务事实不适用，并记录判定证据 | 可以 |
| `UNKNOWN` | 没有读取当前值，或只凭记忆、截图、旧报告推断 | 不可以 |
| `BLOCKED` | 缺资料、验证失败、必填为空、页面未持久化或法律确认未完成 | 不可以 |

保存弹窗、上传预览、绿色对勾和问卷“验证”只证明中间动作。最终证据必须包含页面、字段值、素材身份、保存结果和刷新/重进后的持久化结果。

## 2. 先建立两个循环

### 2.1 语言循环

记录 `应用信息 > 管理语言列表` 中的默认语言和所有附加语言。

- 对每种语言核对应用名称和图标；版本页再核对应用介绍、一句话简介、新版本特性和介绍素材。
- 官方允许未配置语言回退到默认语言，但不要把回退称为已本地化。附加语言若仍显示红色未完善提示，应补齐或移除不准备维护的语言。
- 名称必须与软件包中的应用名称一致；发布地区包含中国大陆时，还受同账号同语言同设备类型和其他开发者 HarmonyOS 应用/元服务重名限制。

### 2.2 素材设备组循环

不要把包内每个 `deviceTypes` 枚举机械映射成单独上传页签。当前官方设备组为：

| 包/发布设备 | 素材设备组 |
| --- | --- |
| 手机、平板 | 手机/平板共用一套素材，统一在 `手机/平板` 页签配置 |
| PC/2in1 | `PC/2in1` 页签 |
| 智能手表、运动手表 | 共用一套素材，统一在 `手表` 页签配置 |
| 智慧屏 | `大屏` 页签 |

执行时仍要读取当前页面页签；若门户与官方文档不同，停止批量操作，记录差异并按当前控件要求准备素材。

## 3. `应用信息` 清单

### 3.1 基本信息与支持设备

| 字段 | 填写/核对规则 | 证据 |
| --- | --- | --- |
| 应用名称 | 每种语言核对；与包内名称和实际品牌一致 | 当前字段值、包内名称、刷新后值 |
| 支持设备 | 平台勾选范围不得超过包内 `module.json5.deviceTypes`；提交前可增减，应用发布后升级版本只可增加、不可删除 | 包元数据、平台勾选项、差异结论 |
| 手机兼容平板 | 中国大陆含手机时，即使包未声明平板，也可能兼容分发到 HarmonyOS NEXT 平板；包已声明平板则直接勾选平板 | 当前包声明与平台提示 |
| PC/2in1 默认分发 | 官方说明手机/平板应用测试后会默认发布到 PC/2in1；提交确认窗可能提示支持设备差异 | 平台当前勾选、提交前提示、风险决定 |
| 操作设备 | 智慧屏适用时核对遥控器等操作设备 | 当前选择 |

手机/平板/PC/2in1/智慧屏目前只在中国大陆提供 HarmonyOS NEXT 客户端分发；当前官方说明境外仅支持智能手表和运动手表。不要凭营销计划选择平台当前不支持的地区。

### 3.2 本地化名称与图标

| 素材设备组 | 数量与分辨率 | 格式/大小 | 其他要求 |
| --- | --- | --- | --- |
| 手机/平板 | 1 张，216×216 或 1024×1024 | PNG ≤ 3MB；WEBP ≤ 100KB 且非动图 | 正方形，与包内图标一致 |
| PC/2in1 | 1 张，216×216 或 1024×1024 | PNG ≤ 3MB | 正方形 |
| 手表 | 1 张，216×216 或 1024×1024 | PNG ≤ 3MB；WEBP ≤ 100KB 且非动图 | 背景透明的正方形 |
| 大屏 | 1 张，1024×1024 | PNG/JPG/JPEG ≤ 3MB；WEBP ≤ 100KB 且非动图 | 与应用一致 |

对每种语言和每个实际显示的素材设备组：上传、读取预览身份、保存、刷新/重进、再次读取。不要为手机和平板重复上传两套相互矛盾的图标。

应用信息保存后，还要在每个发布设备组安装候选版本，核对安装后终端显示的名称、图标与门户名称、图标一致。检查 AppScope、EntryAbility、默认语言和本地化覆盖；资源引用相同但未做实际安装不标记 `PASS`。

### 3.3 应用分类、标签

- 选择一个当前平台提供的应用分类/二级分类，记录实际字段值。
- 最多选择 5 个标签；只要选择标签，就必须设置其中一个为主标签。
- 主标签必须与二级分类关联。运动手表当前只配置分类，不支持标签。
- 保存并刷新后再次读取分类、全部标签和主标签。

### 3.4 开发者服务信息

供应商和开发者名称来自账号，通常只读。按当前页面必填性和实际服务能力填写：

| 字段 | 规则 |
| --- | --- |
| 官网 | 合法的 `http://` 或 `https://` URL；发布前实际访问，不能是 404、占位页或无关页面 |
| 客服电话 | 采用国际区号/国内区号格式，如 `0086-...` 或 `0755-...` |
| 客服邮箱 | 标准邮箱格式，并确认能接收用户邮件 |
| 客服 QQ | 仅在真实提供该渠道时填写 |
| App 内问题反馈路径 | 写用户在应用内能够真实完成的导航路径；没有入口时不得杜撰 |

开发者服务信息是面向用户的公开信息，不等于版本页的审核负责人联系方式。

## 4. 软件包管理清单

### 4.1 上传前

- 项目级 `assembleApp` 产出 release 签名 `.app`，不是 `.hap`。
- APP 总大小不超过 4GB；包内 HAP 上限按设备类型判断：手机/平板/PC/2in1 ≤ 4GB，智能手表/智慧屏 ≤ 2GB，运动手表 ≤ 20MB；多设备 HAP 取所支持设备上限的最小值。
- 所有 HAP 均为非免安装应用；Stage 模型 `bundleType` 为 `app` 或缺省等同 `app`。
- API Level ≥ 10；API Level ≥ 11 时包内不可带 `debug=true`。
- 独立验包记录 Bundle Name、versionName/versionCode/buildVersion、compatible API、target API、设备类型、字节数、SHA-256、签名摘要和 Profile。
- `compatibleSdkVersion` 是最低兼容能力，`targetSdkVersion` 是目标能力；审核报告中的 `minAPIVersion` 必须回溯到被审核软件包，不能用当前本地配置覆盖旧包事实。
- 下调 compatible API 前检查依赖与 API 调用是否在该版本可用，并补相应构建、自动化或设备/云测证据；只改数字不通过。

### 4.2 上传与解析

上传弹窗先选择使用场景：正式发布使用 `测试和正式上架`。只有随后选择并上传精确 `.app`，且页面新增了匹配记录，才可称为上传成功。

逐列回读：文件名、包名、版本名/版本号、构建版本、设备类型、使用场景、上传时间、合法性、上架自检。

合法性语义：

- `已达标`：允许提交上架。
- `待优化`：允许提交，但存在审核或体验风险；读取报告并决定是否修复。
- `不通过`：不允许上架，必须修复并上传新包。

官方“上传软件包”页把合法性 `待优化` 描述为允许提交，而“选择待发布软件包”页把 `已达标` 列为选择前提。默认只放行 `已达标`。如果当前版本选取窗口明确允许选中该精确 `待优化` 包，必须先读取报告并让用户针对该报告明确接受驳回/体验风险，随后才可选取并把偏差写入提交摘要；没有风险接受或页面不允许选取时均标记 `BLOCKED`，不得用前一页文字绕过。

### 4.3 上架自检

上架自检是华为官方推荐项，不是合法性检测的同义词：

- 每个应用同时只能有 1 个自检任务；删除软件包不会停止已启动任务。
- `通过` 才能记录为通过；读取报告身份和检查维度。
- `待优化` 官方说明不阻止提交，但存在被审核驳回风险。读取异常/日志，并在提交前由用户选择修复或明确接受风险。
- `系统异常` 不是通过；读取原因或重新启动。
- 若决定不运行自检，提交摘要必须写 `未运行（官方推荐项）` 和风险，不能写成通过或忽略该行。

报告必须与本次上传一一绑定：报告 ID、测试起止时间晚于上传时间、版本、Bundle Name、软件包行和设备任务均匹配。不要取“最新一条”替代身份核对。

## 5. 待发布版本清单

### 5.1 选择软件包与加密

- 默认只选择使用场景为 `测试和正式上架` 且合法性为 `已达标` 的精确软件包。若精确 `待优化` 包在当前窗口实际可选，只能按 4.2 的报告核对与用户风险接受例外继续。
- 回读文件名、版本、构建版本、上传时间和设备；点击选取后保存并刷新复核“已选软件包”。上传成功但版本选取仍显示旧包时标记 `BLOCKED`。
- API Level ≥ 11 时可选择加密/不加密：加密侧重包安全，不加密侧重启动速度；仅运动手表不支持加密。记录实际选择和理由，不把“推荐”当作用户决定。
- 已下架正式版本重新上架时，VersionCode 必须高于历史全网版本。

### 5.2 发布国家或地区

- 记录 `所有国家或地区` 或精确的 `特定国家或地区` 列表。
- 选择中国大陆以外地区时，按页面要求处理应用数据出境声明；法律声明由用户确认。
- 地区变化会改变素材语言、版权、备案和隐私要求；先重算适用项，再保存。

### 5.3 本地化介绍、特性与素材

对每种语言填写并复核：

| 字段 | 必填性/限制 |
| --- | --- |
| 应用介绍 | 必填，≤ 8000 字符；描述真实功能和产品定位 |
| 应用一句话简介（小编推荐） | 必填；中文 ≤ 17 字符，其他语言 ≤ 80 字符 |
| 新版本特性 | 选填；中国大陆 ≤ 500 字符，非中国大陆 ≤ 1000 字符；升级版本会展示在更新页 |

素材规范：

一句话简介必须是完整功能句：明确应用帮助用户完成的动作、对象或直接结果，并与实际功能、应用介绍和截图相符。字符数合规但只有营销口号、宽泛收益、关键词堆砌或句意残缺时仍标记 `BLOCKED`。

| 素材设备组 | 应用介绍截图 | 可选视频/其他素材 |
| --- | --- | --- |
| 手机/平板 | 横向 3-5张，16:9，1920×1080；或竖向 3-5张，9:16，1080×1920；PNG/JPG/JPEG ≤ 5MB，WEBP ≤ 200KB 且非动图 | 同设备组截图与介绍视频方向一致；介绍视频 1-3 个，横向 1280×720 或竖向 720×1280，MOV/MP4 ≤ 500MB，15 秒至 2 分钟 |
| PC/2in1 | 3-5张，16:9，1920×1080，PNG/JPG/JPEG ≤ 5MB | 以当前控件为准 |
| 手表 | 4-8张，1:1，840×840，PNG/JPG/JPEG ≤ 2MB，WEBP ≤ 100KB 且非动图 | 截图为正方形 |
| 大屏 | 5-8张，16:9，1920×1080，PNG/JPG/JPEG ≤ 2MB，WEBP ≤ 100KB 且非动图 | 推荐图第 1 张 396×223 必传、第 2 张 414×573 必传；第 3 张 1920×1080 和第 4 张 880×494 选填，格式/大小按官方表 |

截图必须来自当前待发布版本或等价的已验收构建，画面无敏感信息、调试浮层、系统通知、裁切错误或不可见文字。上传前逐张检查真实渲染；上传后核对数量、方向、顺序、预览，再保存和刷新。截图检查发现的 UI 缺陷必须回到代码修复和完整重发循环，不能只修图。

### 5.4 应用内资费与商品

- 有收费时选择所有实际资费类型：激活、道具、关卡、虚拟币、部分章节、课程、会员或其他。
- 有数字商品时核对消耗型、非消耗型、自动续期订阅、非续期订阅；新版本增加商品类型时，需带该类型商品一起审核。
- 无收费、支付和商品时，记录代码/产品证据并将相应行标记 `N/A`；不要虚构收费类型。
- 当前门户若另有免费/付费、币种或价格字段，读取并记录实际值。

### 5.5 内容分级

1. 点击设置并填写调查问卷，所有答案与当前功能、内容和地区一致。
2. `保存` 只保存中间答案；完成后点击 `验证` 取得计算结果。
3. 基于最低结果选择等于或更高的适龄等级，点击 `提交`，再回到版本页确认结果已回写。
4. 最终等级为 3、8 或 12 时，回答是否仅面向儿童；选“是”且分类不是儿童类时，必须回到应用信息调整分类。
5. 问卷更新或新版本改变答案时重新填写。`拒绝评级` 必须修复内容后再上传，不能绕过。

### 5.6 隐私三条独立证据链

#### A. 应用隐私说明（权限）

- 由软件包检测触发。敏感隐私权限：逐权限填写使用理由；若系统已从 `module.json5.reason` 自动填充，仍需核对一致性。
- 受限开放权限：逐权限填写 ≤ 500 字符的理由，并上传使用场景视频；MOV/MP4、H.264、≤ 500MB。
- 发布 Profile 必须申请包中声明的受限开放权限，否则会被驳回。权限、Profile、代码使用场景和政策声明四者一致。

#### B. 隐私声明（政策）

使用自定义政策时至少核对两个独立入口。当前门户可能允许两个字段填写同一 URL，也可能要求不同 URL；不得预设。即使 URL 相同，也要分别证明政策正文和权利行使方式可以直接找到：

| 字段 | 证据 |
| --- | --- |
| 隐私政策网址 | 无需登录即可访问，HTTP 成功，正文明确应用名称、处理目的/方式/范围，并与实际行为一致 |
| 隐私权利 | 无需登录即可访问，说明用户删除、修改、导出或其他适用权利的入口与方式 |

网址返回 404、仅有占位内容、跳转到无关页面或与应用数据流冲突时标记 `BLOCKED`，不要写入门户冒充完成。

使用华为隐私托管时：当前仅支持发布地区包含中国大陆且设备为手机、平板或 PC/2in1 的 HarmonyOS 应用；由用户接受平台法律条款。逐模块配置导语、收集/使用、权限、未成年人、第三方共享、第三方 SDK、个人信息管理、存储地点/期限、联系信息、生效日期及适用的自定义章节；预览后生成状态为 `完成` 的协议，并在版本页选中该协议。每个版本上线只能关联 1 个隐私政策。

本地优先应用也要准确解释用户自行录入的本地数据、保存期限、删除方式、是否联网、是否有服务器、权限和第三方 SDK；“开发者不收集”不能用来掩盖应用在设备本地处理的数据。

#### C. 隐私标签

手机、平板、PC/2in1、智慧屏应用需要配置：

- 确实不涉及个人信息收集时，`是否涉及个人信息收集` 选择 `否`，并保留代码、具体本地数据类型、权限、网络和 SDK 证据。应用在本机处理普通业务数据不自动等于个人信息收集，也不自动排除个人信息收集；按实际数据项和当前平台定义判断。
- 涉及时选择 `是`；最多勾选 6 种业务场景，每个场景必须添加数据项，红点未清除表示未完成。
- 无广告与营销时不得勾选该业务场景；汇总页复核关联到用户的数据。

隐私政策、权限说明和隐私标签必须互相一致；不能因“应用无账号”就机械地全部选择否。

### 5.7 AI 功能声明

- 不提供人工智能生成合成服务时选择 `不涉及`，记录功能/依赖证据。
- 提供时选择 `涉及`，勾选真实服务类型，并在 `版权信息 > 授权书及其他材料` 上传 AI 生成标识材料和相关资质。

### 5.8 版权信息

| 发布区域 | 电子版权证书 | 应用版权证书或代理证书 |
| --- | --- | --- |
| 包含中国大陆 | 可选；PDF ≤ 5MB，不能靠修改扩展名伪造 PDF | 手机应用必选；JPG/PNG/BMP，每张 ≤ 15MB，最多 10 张 |
| 不包含中国大陆 | 可选；同上 | 可选；同上 |

额外授权书或其他材料可上传 ZIP：≤ 200MB，只含 JPG/JPEG/BMP/PDF，文件夹最多 3 层、累计不超过 200 张图片，解压后总大小不超过 1GB。版权主体、开发者主体、授权链和素材来源由用户确认，不得代替用户作法律事实保证。

### 5.9 核准（APP备案）信息

按实际网络服务形态选择：

| 类型 | 判定与填写 |
| --- | --- |
| 您的 APP 服务器在中国大陆 | 已完成核准/备案；填写主办单位类型、与开发者主体是否一致；不一致时填写名称和证件号，并校验 |
| 您的服务器不在中国大陆 | 仅适用于境外主体运营且服务器只在境外的应用 |
| 您的 APP 为单机APP | 未通过连接公共互联网提供互联网信息服务；用网络权限、代码、运行证据支持判断 |

HarmonyOS 备案与 APP 备案要求一致，由接入商办理时选择 `鸿蒙` 平台；APP 名称、Bundle Name 和主体信息须与上架信息一致。同一应用从 Android/iOS 增加 HarmonyOS 时，需变更备案并增加鸿蒙平台与包名。不要把“本地数据库”自动等同为单机：只要通过公共互联网提供信息服务，就需重新判断。

### 5.10 应用审核信息与联系方式

| 字段 | 规则 |
| --- | --- |
| 需要登录进行审核 | 有登录后功能时勾选，并提供有效测试账号和密码；秘密由用户在门户本地输入，不进聊天和文档 |
| 备注 | 说明审核所需特别设置、入口、数据准备或限制 |
| 自测文件 | 特殊设备/环境适用；`.docx` 单个 ≤ 15MB 或 `.mp4`，最多 5 个，总计 ≤ 500MB；只作补充证据，不替代真实功能 |
| 负责人手机 | 中国大陆账号填写；用于审核沟通 |
| 负责人邮箱 | 接收审核、整改或下架通知 |
| 验证码 | 手机短信验证码验证通过；由用户输入，不记录 |
| 姓名 | 用于沟通核实负责人身份 |

审核负责人联系方式与公开客服信息、隐私联系信息是不同字段；即便值相同，也要分别保存和验证。

### 5.11 审核可达性与功能价值

- 从干净安装开始列出核心用户闭环、入口、前置条件和完成结果；介绍、截图和审核备注中的每个核心能力都必须在 release 构建真实存在。
- 时间、账号、外设或数据条件会阻塞核心功能时，提供正常用户可用的到达路径，或按平台能力提供有效测试账号、受支持环境和必要自测文件。
- 若审核会话只能到达记录、静态展示或单一页面，而宣称的决定、统计、导出等价值无法使用，保持 `BLOCKED`；先修产品可达性或扩充真实功能，再生成新 APP。
- 不得加入仅审核员可见的调试入口、虚假数据或绕过产品规则的审核专用开关。视频和备注只能解释实际可操作路径。

### 5.12 上架时间

- 选择 `审核通过立即上架` 或指定时间；指定时间使用本地时间输入，平台会显示换算后的 UTC，保存前核对两者。
- 指定时间审核通过后，提前上架需点击 `手动发布` 并再次确认；这是独立外部动作，必须取得新的授权。
- 重新使用旧草稿时检查指定时间是否已过期。实际发布后再在目标地区商店端验收。

## 6. 双页持久化预检

### `应用信息`

- 语言列表、每种语言名称；
- 每个素材设备组的图标；
- 支持设备；
- 分类、全部标签、主标签；
- 开发者服务信息；
- 每一块保存成功且刷新/重进后仍存在。

### `版本信息/准备提交`

- 精确软件包与加密；
- 地区和适用的数据出境声明；
- 每种语言的介绍、一句话简介、新版本特性和各素材设备组截图/视频；
- 资费与商品；内容分级已提交回写；
- 应用隐私说明、隐私声明、隐私标签；AI 声明；
- 版权、备案；审核信息、联系人验证；上架时间；
- 每一块保存成功且刷新/重进后仍存在。

页面无红色缺项提示后仍要逐行复核。只有全部适用行均为 `PASS` 或有证据的 `N/A`，才能生成最终提交摘要。

## 7. 审核驳回与重提清单

- 读取审核报告身份：提交时间、报告生成时间、测试环境、应用/Bundle/版本和报告 ID/URL。
- 回到失败版本，读取被审核软件包和当前已选软件包的文件名、版本/构建、上传时间和设备；不要假定“本地最新”就是“审核所用”。
- 建立驳回问题矩阵，逐项记录原文、根因、修改面、是否需新 APP、验证步骤和当前状态。
- 名称/图标、一句话简介、compatible/target API、功能价值/审核可达性分别按本清单复核。
- 包或功能变化后重新测试、签名、验包、上传、版本选取、保存和重载；只改门户字段时也要保存并重载。
- 只有全部适用项具有新证据并且当前版本明确选中替换包，才可展示重提摘要；`重新提交审核`需要新的动作时授权。

## 8. 实操校正

- 上传截图前检查真实帧可以提前发现对比度、裁切和适配问题；发现缺陷后回到源码、设备验收、签名 APP、验包和上传全循环。
- 文件选择器超时或浏览器返回 `Not allowed` 时，不要反复复制素材到不同目录；按浏览器能力使用文件选择事件，或让用户手动选择，再回读远端记录。
- 软件包上传弹窗可能先要求选择使用场景；仅点击上传控件不代表文件已传送。
- 公开隐私页必须先实际访问；失效 URL 不得写入门户。托管政策生成后还必须在版本页选中并保存。
- 年龄问卷 `验证` 后仍需 `提交`，并在版本页看见回写结果。
- 已上传且合法性达标、自检未检测、已保存草稿、已提交审核和已上架是不同状态。
- 驳回后上传新包但未在版本中选取、保存和重载时，审核仍可能使用旧包；上传记录不是版本选取证据。
